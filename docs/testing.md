# Testing

`npm run check` performs a strict TypeScript build, transport tests and fixed-vector webhook verification tests. The protected **Customer account live** workflow allocates a dedicated short-lived platform fixture and must fail—not skip—when its allocator credential is absent. It exercises an anonymous cart with a real item, password sign-in, explicit cart merge, profile update, complete address create/update/default/list/delete behavior, customer order and return collection reads, refresh rotation/replay rejection and logout revocation. Its `finally` release removes the synthetic customer, refresh credentials and fixture cart even after a failed assertion. Webhook tests use exact deterministic bytes; a later receiver qualification job must exercise actual delivery, retry and replay through an external HTTPS endpoint.
